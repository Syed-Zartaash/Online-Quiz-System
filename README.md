# Online Quiz System

A simple **Online Quiz System** developed as a mini project for my **ICT (Information and Communication Technology)** course.

## 📌 About the Project

This project is a basic 5-question online quiz system built using **C, HTML, and CSS**. Users can answer the questions and, at the end of the quiz, the system calculates their **total score** and provides feedback on whether they should study more.

The project is intentionally kept simple as a mini project, but the concept can be expanded into a complete **University Learning Management System (LMS)** with features such as user accounts, randomized questions, multiple quizzes, subjects, results tracking, and more.

## 🛠️ Technologies Used

* **C** — Quiz logic and score calculation
* **HTML** — Website structure
* **CSS** — Styling and layout
* **XAMPP** — Local development and testing

## ✨ Features

* 5-question quiz
* Simple and user-friendly interface
* Automatic score calculation
* Final performance feedback
* Runs locally using XAMPP
* Can be expanded into a larger LMS project

## 🚀 Future Improvements

Some possible improvements include:

* Randomized questions
* Larger question database
* Multiple subjects and quizzes
* User login and registration
* Database integration
* Student result history
* Teacher/admin dashboard
* Full University LMS functionality

## 🎓 Project Purpose

This project was created to apply the programming and web-development concepts learned during my ICT course and to explore how a simple quiz system can serve as the foundation for a much larger educational platform.
